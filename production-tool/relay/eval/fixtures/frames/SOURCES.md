# Eval frames: sources

The storyboard stills the director eval's `frame_edit` cases send to Dex as the current frame
(`eval/director_cases.json`, `frames`). Each one is drawn from plain shapes by
`make_frames.py` in this folder. No photo, no third-party picture and no client material
is involved. Running the script again gives the same pixels.
