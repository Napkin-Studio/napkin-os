The new UI

How Napkin Studio's new interface looks and behaves, taken from the code and the live build: tokens, agency looks, the Deep O mark, the agents, the shell, Brief and Research, and the patterns between them. Every value names its source file. Where the live build and its design differ, the page says so.

How to use it

  • Start with Principles, then Foundations.
  • Building a screen: read its page, check the do/don't pairs, and copy the exact tokens and classes from the code paths given.
  • Before shipping: check Copy rules and add anything that does not match to Known gaps.
  • For agents: README.md in this folder has a summary in text.
