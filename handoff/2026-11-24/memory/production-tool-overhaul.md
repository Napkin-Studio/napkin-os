Production Tool overhaul, owner (Shrey) decisions on 2026-10-13:
- Vision: the canvas is where everything comes together. Typed nodes (Script, Storyboard, Video...), drawing and references stay; linking Script + Storyboard makes a Video node; double-click opens a full editor (script, storyboard, image editor "close to Photoshop", video editor). Laurence O Byrne's review (2026-10-10, 11 items) is solved inside the overhaul, not as a separate fix pass.
- Straight to the overhaul: no separate "fix 8/10/5 on today's UI" slice.
- Audience: external paying customers first (multi-tenant, caps, privacy).
- Licences: permissive OSS (MIT/Apache/BSD/ISC). NEVER buy a software licence ("not buying is the one rule"), so tldraw, Tiptap Pro, Remotion etc. are out for good. Exceptions agreed 2026-10-13: MPL-2.0 libraries allowed if installed from npm and never modified (e.g. Mediabunny); GPL allowed on the server only, never shipped to clients (keep the GPL ffmpeg build). No non-commercial model weights. Hosted APIs we already pay for (Runway, Bedrock) are fine.
- Licence rulings (2026-10-13): PyMuPDF (AGPL) replaced by pypdfium2 in the engine; NVIDIA CUDA wheels for the engine's local fallback models (judge_local/embed_local) allowed SERVER-ONLY; MIT-0, BSL-1.0, PSF-2.0, CC-BY-4.0 (attribution), PyPI 'BSD License', OpenMDW-1.1 approved as permissive.
- Font rulings (2026-10-13, NOT yet applied): swap Excalidraw's Liberation Sans 1.x (GPL) for Liberation 2.x (OFL) and its Windows-supplied Cascadia Code for the upstream OFL release; apply on feat/licence-gate / web build.
- CC0 and OFL-1.1 count as permissive (2026-10-13); so do Zlib, Unicode-3.0, Unlicense, BlueOak. MPL-2.0 unmodified is allowed from any registry (crates.io too), not only npm.
- First designs (2026-10-13): keep today's three-stage UI working on contract v3; projects and library shared per agency (tenant) from os-sign-in on; staging keeps the passwordless roster for now.
- Canvas foundation: DECIDED 2026-10-14: build OUR OWN canvas engine (grow Spike O: MIT @tldraw/store+state, canvas2d, perfect-freehand, rbush, DOM nodes, Yjs) behind CanvasAdapter; Excalidraw runs today's tool until parity. Device runs were skipped by the owner (desktop numbers: Excalidraw failed pan gate). Feature: canvas-engine.
- Live multi-user collaboration must work before the first external customer (early features write via a patch interface).
- The tool moves inside napkin-web at /production (same origin, shared sign-in); Advertising Studio is likely retired.
- Devices: desktop + iPad with Pencil + phone for view/review.
- Script editor: both screenplay and two-column AV views from the start.
- Data to Claude/Bedrock and Runway-routed models: per-tenant allowlist.
- Old hackathon/dogfood projects: keep the S3 data and AWS logs as they are; no importer; remove the rest.
- Crew (2026-10-13): Dex directs (cobalt hex, viewfinder), Skye scripts (coral column, page), Wren renders = on screen while Runway makes a frame/clip (marigold star, spark), Rhea retouches = image editor (mint dome, dots), Edie edits = video editor/splice/render (iris stack, bars); house Ellis reads (notes, handwriting), Jude checks. Later an audio agent.
- Loader (owner, 2026-10-13, final): the Napkin logo in ITS OWN colours only (never agent colours). A centre pin; the leading quadrant revolves around it and the other three fan out behind it, each sliding out from under the one ahead like cards, into the full logo; the whole logo spins once; the cards fold back under the lead; repeat. Lead = department: create/orange generating, plan/ink planning-directing-writing, learn/light grey reading-researching-checking, produce/grey cutting-rendering-sizes-export. Finish: still full logo 0.6 s. Queued: still logo. Same loader on the pointer.
- Inputs (2026-10-13): a generating node's scope comes from links (boards, groups, single refs, notes); using an unlinked @ref auto-adds the link with a toast. Links are quiet grey lines that light up on select (inputs glow, used refs tagged, rest dims), each node has an inputs strip, 'Show all links' toggle. A 'What Dex will send' tray appears before every generation (collapsible): sketch-area strokes = layout, text = instruction, marks on a picture = markup (clean + marked copy, Ellis reads handwriting), outside notes only if linked. Ref names unique project-wide (Runway tags).
- Asks (2026-10-13): like the Research tool's clan Ask (question {id,text,options,allow_text,address}, job state needs_input, answer = human 'confirmed' write). Each tool works on its own; when input is thin or ambiguous the agent asks instead of guessing, nudging toward the flow (e.g. video with nothing -> ask for a prompt; video from a raw script -> 'plan a storyboard first?' and if declined the script is fed). Block only when it truly cannot proceed.
- Assets (2026-10-13): an Assets drawer with sources This project / Team library / Upload / From Napkin (spin-in from Brief Maker and Research via OS spin-off upstream+lift). Uploads are read into the right thing (images/logos -> refs; character sheets split into views by Rhea; brand books -> Brand board by Ellis: logos, palette, font names, tone, rules; docs -> Document node; Fountain/FDX -> Script). Brand rules guide prompts and Jude warns on breaks (never blocks). Team library organised by client/brand within the agency. Spin-off only inward for now; outward is export + library. Client material stays tenant-scoped, never in the repo.
- Script may link straight to a Video (owner 2026-10-13); on Make video Dex asks 'Plan a storyboard first?' (recommended) or 'Make clips straight from the script'.
- Asks are shared (owner 2026-10-13): any collaborator can answer; History records who.
- Scamp sheets and formats (2026-10-13): a Sheets picker drops ratio-locked format sheets (packs: Social, Out of home, Print, Digital display, plus storyboard frames and custom per client) one click away; 'Make all sizes' from a key visual adapts it to every size in a pack (crop or extend on Runway, logo/copy in safe areas per Brand board, Ask for the subject when unclear, cost in the send tray) into a Format set node; VIDEO cut-downs (9:16, 1:1, 4:5 from the 16:9 film) are in from the start too.
- SOUND + MODELS (owner 2026-10-14): integrate Sai's Runway Model Research (docs/production-tool/model-research-2026-10-13.md etc., .clan in docs/production-tool/runway-model-research.clan): path per shot (Path 1 native-audio video for on-camera speech; Path 2 silent + ElevenLabs layers; Napkin Radio = radio export only), coherence rules R1-R6, text frames never to video, per-shot moderation fallback, model picks (nano_banana_2.1, ideogram_4_5 mask, h3_max/veo3.1_fast/veo3.1, gen4_turbo/gen4.5/wan3, aleph2 range keeps audio). ElevenLabs is the second provider (direct). Features: model-swap, audio-contracts, audio-native, audio-elevenlabs, audio-mix, audio-director, audio-music, audio-ui, lipsync, radio-bridge.
- COSTS (owner 2026-10-13, supersedes earlier spend rules): no prices/costs anywhere in the UI; costs recorded per job and shown only in the decision tree. Send tray stays, no prices. Spend caps built but OFF, chosen by each agency later (not Napkin); daily quotas mechanism kept, off; global spend stop kept as invisible backstop. Failed/moderated attempts Runway bills are charged silently. 0BSD approved.
- Staging safety stop: $500 headroom (owner 2026-10-14). ElevenLabs keys come later, at testing time.
- UI tokens (2026-10-13): primary buttons #D63B1F (hover #B8321A); brand orange #FF4F2E only on the mark, loader, needs-you dots, ask borders, textless accents; grey text #6B7180; tool-blue text #1E4ED8 (fills #2F64F5); green text #166534. Loader settles into the full mark for 0.6 s on finish (not under reduced motion). Spend tray opens expanded for batches and any action > $2; caps from a per-ad cost model (to write). Format packs from industry standards, kept as data (format-packs.json), owner reviews.
- Agents must be drawn in the house figure language (AgentFigure: flat bodies, ink legs and feet, pill eyes, one mark, idle/working/needs-you), never simplified shapes; our crew is our own, rendered with the real component.
