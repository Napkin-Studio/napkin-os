# ADR-004 providers: who receives client text

One row for each provider named in the model routes (`server/napkin/model_routes.py`, `server/model-routes.example.json`, `NAPKIN_MODEL_API`) and in the web search configuration (`NAPKIN_RESEARCH_WEB`, `server/napkin/websearch.py`). Only what the repo or the provider's public documentation states is written here. Where neither does, the cell reads **not recorded**. Nothing here has been checked against a contract, an invoice or an account.

"DPA signed" is **not recorded** for every provider: no data processing agreement is held in the repo. Who holds them is an open question in `features/client-wall.clan`.
