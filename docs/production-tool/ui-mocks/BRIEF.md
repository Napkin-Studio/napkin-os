## Format rules (the Design canvas .dc.html format; each mistake fails silently)
- Copy Main.dc.html's skeleton exactly: doctype, `<html lang="en">`, head with charset, a `<title>`, and EXACTLY `<script src="./support.js"></script>`; body has `<x-dc>` containing `<helmet>` (the same Google Fonts `<link>` and a `<style>` with only page basics: body{margin:0}, a/a:hover colours, helper classes like .grid) and ONE root div with a FIXED size equal to the artboard (e.g. width: 1440px; height: 900px), position relative, overflow hidden.
- After `</x-dc>`, ALWAYS the block `<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":W,"height":H}}'>` with `class Component extends DCLogic { renderVals() { return {...}; } }` (classic JS, no imports).
- Styling inline `style="…"`; layout with flex/grid + gap; absolute positioning is fine for canvas scenes.
- Close every non-void element; quote every attribute. `{{hole}}` is only a dotted lookup into renderVals() (never an expression). Events: `onClick="{{ fn }}"` with fn returned from renderVals(); state via this.state/this.setState. Loops `<sc-for list="{{items}}" as="item" hint-placeholder-count="3">`, conditionals `<sc-if value="{{flag}}" hint-placeholder-val="{{ true }}">`.
- Real `<button>`, `<a href>`, `<input>`/`<textarea>` with `<label>` or aria-label; icon-only buttons need aria-label; decorative SVG `aria-hidden="true"`. No emoji. No `<iframe>`, `<object>`, `<embed>`, no external images, no network except the fonts link. No global keydown handlers. Never build UI from script (no innerHTML/appendChild).
- Text contrast 4.5:1; touch targets >= 44px on the tablet and phone artboards.
- Copy is real, short, plain English, written from the user's side ("Make video", "Insert a shot here"); no lorem ipsum, no rationale text inside the artboard. Small callout pins are allowed ONLY if styled as part of the UI (e.g. a tooltip or toast), not as designer notes.
