The Deck and Production prompt

fable-master-prompt-deck-production.md: read, not acted on. It asks for mocks of Deck Maker and Production in the Brief Maker and Research design language, with the Booth, then a hard stop for Shrey's approval, then the build.

Where it fits

  • It is Phase 3 and 4 territory (Production, Deck Maker), with a clearer design language than v3.1 gave.
  • Its first phase is mocks only, outside the repo, so it can run beside the Phase 2 build without touching code.
  • Its rules also reach back into Phase 2 screens: the Booth, no chatbots, Needs you as the one list, point-at-it feedback.

Where it disagrees with this build

  • Branch rule. It says pull requests into develop. This build is one branch, no pull requests.
  • Prices. It says no prices anywhere in the UI. v2 and the Ask Nap design show the cost before a run.
  • Chat. It says no chat panel in any tool. Ask Nap is close to one.
  • Owner. Shrey approves there; here approvals are yours, with Laurence's relayed.
  • Builders. Two at once there, three here.
  • Machine. It names paths on Shrey's Linux machine and mocks in ~/Documents/napkin-design-mocks, which this Mac may not have.
